# Scalable URL Shortener

A scalable URL shortener built with **React, ASP.NET Core, PostgreSQL, Redis, and Docker**.

## Overview

This project aims to build a web application that converts long URLs into short, shareable links. Users will be able to manage their URLs, redirect visitors to original destinations, set expiration dates, and view basic click analytics.

The project focuses on backend development, database design, API development, caching, authentication, and scalability.

## Planned Features

- User registration and authentication
- Short URL generation and redirection
- URL expiration and status management
- Basic click analytics
- Caching with Redis
- RESTful API design and documentation

## Technology Stack

- **Frontend:** React + Vite
- **Backend:** C# + ASP.NET Core
- **Database:** PostgreSQL
- **ORM:** Entity Framework Core
- **Caching:** Redis
- **Testing:** xUnit and Postman
- **API Documentation:** OpenAPI / Swagger
- **Containerization:** Docker and Docker Compose

## Project Status

Currently in the planning and architecture design phase. Implementation has not started yet.
